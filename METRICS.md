# Model metrics

Generated by running the notebook flow in `autoML.ipynb` against
`ai_assistant_usage_student_life.csv` on Python 3.11.18 with
pycaret 3.3.2, scikit-learn 1.4.2, numpy 1.26.4 and pandas 2.1.4.

Settings: `session_id=42`, `train_size=0.8`, 5-fold stratified CV on the
training split, `fix_imbalance=True`, `normalize=True`,
`pca=True, pca_components=0.90`.

Selected model: `QuadraticDiscriminantAnalysis(reg_param=0.0)`.
`tune_model` ran but found no improvement, so the shipped pipeline keeps
`reg_param=0.0`.

| Measurement | Accuracy | AUC | F1 | PR-AUC |
|---|---|---|---|---|
| 5-fold CV on train (n=8000) | 0.7394 | 0.6827 | 0.8197 | – |
| Holdout (n=2000) | 0.7320 | 0.6714 | – | 0.7991 |
| Constant "always True" predictor | 0.7065 | 0.5000 | – | 0.7065 |

## Interpretation

The positive class (`UsedAgain=True`) is 70.65% of the holdout rows. A
constant predictor that always answers `True` therefore already scores
0.7065 accuracy, so the model's accuracy is only ~2.6 points better than
predicting the majority class. AUC 0.6714 over 0.5 (and PR-AUC 0.7991
over a 0.7065 no-skill floor) shows the model does rank sessions better
than chance, but the available features carry weak signal.

`SatisfactionRating` ablation (same settings, `compare_models`
restricted to QDA and logistic regression): removing it left CV AUC
essentially unchanged (QDA 0.6827 -> 0.6835, logistic regression
0.6848 -> 0.6854), so the model does not depend on it.

## Reproducing

```bash
uv sync
uv run jupyter nbconvert --to notebook --execute autoML.ipynb
```

`main.py` loads the committed `my_best_pipeline.pkl`, which was trained
with these settings. Retraining will change the artifact digest, so
update `MODEL_SHA256` in `main.py` after re-exporting.
